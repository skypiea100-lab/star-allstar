# 스타 올스타 리그 v21

v20을 기반으로 한 커리어·스토리 확장판입니다. GitHub Pages에 그대로 업로드해서 사용할 수 있습니다.

## v21 핵심 업데이트
- 정규리그 포인트와 순위결정전 포인트를 각각 1위 16P ~ 16위 1P로 통일
- 통산 리그P / 순위결정전P / 종합P 분리 표시
- 경기 종료 직후 상단 승자 배너 강화
- 원본 능력치(baseStats)와 현재 능력치(stats) 분리 저장
- v20 저장 데이터 자동 마이그레이션 및 구버전 900대 능력치 복구 방지
- 저장 / JSON 내보내기 / 불러오기 / 전체 초기화
- 시즌 종료 결산 팝업 및 시즌 어워드
- 정규리그 1위와 최종 우승 커리어 분리
- 최근 5경기 기반 파워랭킹과 순위 변화 표시
- 라이벌 / 천적 / 강한 상대 표시
- 업셋 점수 및 시즌 최대 이변 TOP 5
- 시즌별 성장 이력
- GOAT / Legend / All-Star / Elite / Star / Challenger 커리어 등급
- 명예의 전당 기록 확장
- 역대 시즌 최종 1~16위, 포인트, 어워드, 스토리 보관
- iPhone Safari 대응 레이아웃 유지

## 경기 방식
1. 16인 전체 풀리그: 3전 2선승
2. 정규리그 종료 후 16위 vs 15위부터 스텝래더 순위결정전
3. 일반 순위결정전: 5전 3선승
4. 3위 진입전: 준플레이오프
5. 2위 진입전: 플레이오프
6. 1위전: 결승전, 7전 4선승

## GitHub Pages 배포
저장소 최상단에 `index.html`, `README.md`, `.nojekyll`을 업로드한 뒤 GitHub Pages를 활성화하면 됩니다.
