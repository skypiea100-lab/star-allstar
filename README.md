# 스타 올스타 리그 v20 · 성장 밸런스 복구판

GitHub Pages와 iPhone Safari에서 실행할 수 있는 정적 웹앱입니다. 별도의 설치나 빌드 과정이 필요하지 않습니다.

선수 초기 능력치는 기존 성장형 밸런스로 복구했습니다. 박성덕은 평균 536으로 처음부터 전체 1위이며, 모든 선수는 500점 안팎에서 시작해 능력별 최대 잠재력 1000까지 성장합니다. 기존 v20 저장 데이터가 있으면 처음 실행할 때 초기 능력치만 자동 복구하고 시즌·커리어 기록은 유지합니다.

## GitHub에 올리는 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 압축파일을 푼 뒤, 폴더 안의 파일 전체를 저장소 최상단에 업로드합니다.
3. 저장소의 `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`의 Source를 `Deploy from a branch`로 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택하고 `Save`를 누릅니다.
6. 몇 분 후 표시되는 `https://사용자명.github.io/저장소명/` 주소를 iPhone Safari에서 엽니다.

중요: `index.html`이 저장소 최상단에 있어야 합니다. 압축파일 자체를 저장소에 올리지 말고, 압축을 푼 파일들을 업로드하세요.

## 포함 파일

- `index.html`: 게임 전체 실행 파일
- `.nojekyll`: GitHub Pages가 파일을 그대로 배포하도록 하는 설정
- `README.md`: 업로드 및 실행 안내

## 저장 데이터

게임 기록은 브라우저의 로컬 저장소에 저장됩니다. Safari 방문 기록이나 웹사이트 데이터를 삭제하거나 다른 기기·브라우저로 접속하면 기록이 이어지지 않을 수 있습니다.
