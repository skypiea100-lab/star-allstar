# 스타 올스타 리그 v22

v21 기반 GitHub Pages 배포판입니다. `index.html`을 저장소 최상단에 두고 Pages를 활성화하면 됩니다.

## v22 주요 변경
- 세트별 진행 버튼: 1세트씩 진행하거나 경기 끝까지 진행 가능
- 진행 중 세트 스코어와 세트별 승자/맵 표시
- 경기 화면에 현재 순위, 시즌 전적, 세트 득실, 최근 5경기, 폼, 통산 전적, 상대전적 표시
- 내 경기까지 자동 진행 버튼 유지 및 강화
- BIG MATCH 자동 표시: 상위권 맞대결/라이벌/PO/결승
- 폼 표시: 절정/상승/보통/하락/부진
- 순위 경쟁 구간 및 선택 선수 시즌 목표 표시
- 성장 시스템 랜덤성 강화: 선수 원래 성향 70% + 랜덤 30%, 성장 폭 확률화, 낮은 확률의 재능 폭발 이벤트
- v21 저장 데이터를 v22 저장소로 자동 마이그레이션
- 모바일 경기 정보 UI 최적화
